# EB Connect – Electricity Board Connections

EB Connect is a full-stack web application for managing electricity connections, customer applications, bills, and payments.

## Technologies Used
- **Frontend:** React.js, React Bootstrap
- **Backend:** Python, Django, Django REST Framework
- **Database:** SQLite
- **Authentication:** JWT
- **API:** REST API with Axios

## Features
- Customer and Admin Login
- Dashboard and Profile
- Apply for Electricity Connection
- Application Approval and Connection Management
- Electricity Bills and Payments
- CSV Customer Import
- Search, Filters, and Responsive UI
- Role-Based Access Control

## Installation

**Frontend**
```bash
cd frontend
npm install
npm start
```

**Backend**
```bash
cd backend
python -m venv venv
```
***Refer: Backend *readme.md* file. ***

Activate the virtual environment and install the project dependencies:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
